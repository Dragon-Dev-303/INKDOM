# Inkdom: controls card

Two players share one keyboard. Print this page and keep it next to the keyboard.

## Player 1 (left hand side)

| Action | Key |
|---|---|
| Move left / right | **A** / **D** |
| Jump | tap **W** |
| Climb up a stair (stand at its foot) or the ladder | hold **W** |
| Go down a stair (stand at its top) or the ladder | hold **S** |
| Punch | **F** |
| Kick | **G** |
| Weapon strike | **H** |
| Block (front only) | hold **R** |
| Squad command (FOLLOW → HOLD → ATTACK) | **Q** |

## Player 2 (right hand side)

| Action | Key | Laptop alternative |
|---|---|---|
| Move left / right | **←** / **→** | |
| Jump | tap **↑** | |
| Climb up stairs / ladder | hold **↑** | |
| Go down stairs / ladder | hold **↓** | |
| Punch | **Numpad 1** | **K** |
| Kick | **Numpad 2** | **L** |
| Weapon strike | **Numpad 3** | **;** |
| Block (front only) | hold **Numpad 0** | hold **I** |
| Squad command | **Numpad Enter** | **P** |

## Both players

| Action | Key |
|---|---|
| Pause / resume | **Esc** (or Backspace) |
| Mute | **M** |

## Rules in one breath
Attackers (▲) start in the street and must stand in the rooftop flag zone for **8 seconds with no defender inside**. Defenders (■) win if the **5:00** timer runs out first. A KO isn't a loss: bosses respawn after 5 s, bots after 8 s.

## Tips
- The outside ladder to the floor-2 window is a shortcut.
- Walk off a stairwell opening (yellow marks) to drop a floor.
- The iron bar breaks blocks. The sword is quicker with more reach.
- Many hits in a row knock a fighter down. At most two bots attack one target at a time.

> Keyboard note: some cheap keyboards drop keys when many are held at once (ghosting). If a key combination stops registering, Player 2 can use the laptop alternative keys.
