# Inkdom: controls and combos

Keys can be changed in **Settings → Controls**. Fwd/Back are relative to the way your fighter faces.

## Single player (vs CPU) and online: one keyboard per player

| Action | Key |
|---|---|
| Move | **A / D** (or ← / →) |
| Jump (tap) · climb stairs/ladder (hold at the foot) | **W** |
| Crouch · go down stairs/ladder (at the top) | **S** |
| Punch | **J** |
| Kick | **K** |
| Heavy (crushes guard, uses stamina) | **U** |
| Weapon (elbow when unarmed) | **I** |
| Special (uses energy) | **O** |
| Block (hold; add **S** to block low) | **L** |
| Dodge (invulnerable backstep) | **Space** |
| Squad command (FOLLOW → HOLD → ATTACK) | **Q** |

| Move | Input | Notes |
|---|---|---|
| Jab → Cross → Lead hook → Rear uppercut | J → J → J → J | Last hit launches and knocks down |
| Roundhouse kick | J → K | |
| Power straight | J → U | Crushes guard |
| Elbow (unarmed) / weapon strike (armed) | J → I | |
| Spinning backfist | J → O | 25 energy |
| Low kick | J → J → K | Must be blocked low |
| Front kick → Roundhouse → Side kick | K → K → K | Big pushback |
| Lunge punch | Fwd + J | Covers distance |
| Knee | Fwd + K | Small launch |
| Back kick | tap Back + K | Turns and kicks; knockdown |
| Crouching uppercut | Down + J | Anti-air launcher |
| Leg sweep | Down + K | Low, knockdown |
| Axe kick | U + K together | Overhead (beats crouch block) |
| Tornado kick | O | 50 energy, knockdown |
| Diving punch / Flying kick | J / K in the air | Overheads |
| Sword: slash → backslash → thrust | I → I → I | Sword only |
| Bar: smash → sweep | I → I | Smash breaks any block |

The full list with frame data is on the **Move list** page (`/moves`).

## Rules of combat
- A standing block stops high and mid attacks. Hold **down** while blocking to stop lows. Overheads beat a crouching block.
- Hitting an opponent while they start an attack is a **COUNTER**: +20% damage.
- Each extra hit in a combo deals 10% less (down to 30%). At most 3 hits in the air, then the opponent falls.
- **Stamina** (green): dodges, heavies and blocking spend it. At zero your guard breaks.
- **Energy** (violet): builds when you hit or get hit, and powers specials.

## Local two players on one keyboard

| Action | Player 1 | Player 2 (laptop alternative) |
|---|---|---|
| Move / jump / crouch | A D / W / S | ← → / ↑ / ↓ |
| Punch · Kick · Heavy | F · G · T | Num1 · Num2 · Num4 (K · L · O) |
| Weapon · Special | H · Y | Num3 · Num6 (; · P) |
| Block · Dodge | R · L-Shift | Num0 · Num5 (I · U) |
| Squad command | Q | Num Enter (Enter) |

Both: **Esc** pauses (in online play it opens the menu, but the match keeps running), **M** mutes.
